# Zentect AI Daemon Python 依赖
# 安装命令：<ai-env>/python.exe -m pip install -r requirements.txt --no-warn-script-location
#
# Python 版本：3.12.x (embeddable)
# 已验证版本组合：在 resources/ai-env (python-3.12.10-embed-amd64) 下全功能跑通
#
# ⚠️ 安装顺序很重要：torch/torchaudio 必须最先安装（CPU 索引），并强制锁定版本，
#    防止后续包（transformers/huggingface_hub 等）通过依赖解析把 torch 升级到不兼容的版本。
#    如检测到 torch 被升级，执行：
#      python.exe -m pip install torch==2.7.0 torchaudio==2.7.0 \
#        --index-url https://download.pytorch.org/whl/cpu --force-reinstall --no-deps
#
# ⚠️ embeddable Python 3.12 DLL 限制（2026-07-28 验证）：
#    - torch > 2.7.0 在 embeddable Python 下 c10.dll 初始化失败
#    - onnxruntime > 1.20.1 在 embeddable Python 下 pybind DLL 失败
#    - sentencepiece 0.1.99 在 Python 3.12 embeddable 下加载 bpe.model 时 ACCESS_VIOLATION
#    - sentencepiece 0.2.2 在 Python 3.12 下 _sentencepiece.pyd 内存访问冲突
#    - sentencepiece 0.2.0 在 Python 3.12 embeddable 下验证通过（SenseVoice bpe.model 加载成功）
#    如改用完整 Python 安装，可尝试升级上述包
#
# ⚠️ 2026-07-28 修复记录：
#    ai-env 中 sentencepiece 被意外升级到 0.2.2，导致 SenseVoice 分词器加载崩溃
#    (exit code: 3221225477 ACCESS_VIOLATION)。
#    修复过程：
#      1. 先降级到 0.1.99 → 仍然崩溃（0.1.99 的 C 扩展在 Python 3.12 embeddable 下加载 bpe.model 失败）
#      2. 改用 0.2.0 → 加载成功，SenseVoice 模型完整加载通过
#    验证：torch 2.7.0+cpu + sentencepiece 0.2.0 + funasr 1.3.29 三者导入和模型加载均正常。
#    根因：某次 pip install 时依赖解析将 sentencepiece 拉到 0.2.2，
#          0.2.2 的 C 扩展 _sentencepiece.pyd 在 Python 3.12 下有内存访问冲突 bug。
#          0.1.99 在完整 Python 3.12 下可工作，但在 embeddable 环境下加载 bpe.model 崩溃。
#          0.2.0 是 Python 3.12 embeddable 下唯一验证通过的版本。
