方案 A · 向导 + 结构化面板

6 个页面 · 已有

01一键成片向导

三步完成：选素材 → 选配方 → 开始前检查。展示口播解说 / 混剪卡点 / 影视解说三套配方，以及时长、画幅、音色、字幕四个核心选项。

打开页面

02任务中心

编辑器内的悬浮胶囊与右侧抽屉。展示 5 步进度、子步骤状态、预计剩余时间、失败详情与「重试此步 / 转手动」，并保留最近任务。

打开页面

03参数收敛左栏

当前配方卡 + 素材助理四个紧凑子步骤行。技术参数默认隐藏，只露出镜头密度这类创作者语言；齿轮进入高级设置，底部保留专家模式。

打开页面

04变更影响预览

高级设置抽屉中修改台词识别模型后，弹出影响清单：哪些步骤会重跑、哪些不受影响、预计增加多久，确认后才应用。

打开页面

05自动模式检查点

自动模式不再一路跑到底：首席编剧完成后暂停确认脚本，专业播音完成后可试听。展示「换一版 / 编辑文案 / 继续」与分段试听。

打开页面

06导出前检查

过期产物硬阻断的界面表达：逐项列出受影响步骤与原因，提供「一键更新过期产物」；修复后切换为可导出的双出口状态。

打开页面

方案 B · 对话式编排

8 个页面 · 新增

对话只做入口和编排：起片、改口味、解释失败、发起重跑。所有产物仍然落在结构化检查点里， 每次执行前都要经过一张动作卡，写清改什么、影响哪几步、要多久。覆盖入口、编排、三个检查点、任务中心、动作卡和失败修复。

C1首页对话入口

一句话起片，也可以直接拖素材。右侧保留进行中项目、最近项目与常用配方，对话不是唯一入口。

打开页面

C2对话工作台

对话流里内嵌制作方案、生成进度、检查点、修改 diff；右侧栏同步产物有效性与当前配方，对话与工作区不割裂。

打开页面

C3素材准备检查点

素材清单 + 四个子步骤结果 + 台词片段与人物。技术词改为镜头密度、人声/背景，过期提示说清影响哪几步。

打开页面

C4内容定稿检查点

脚本确认与配音试听双 Tab。左侧保留“来自对话”的偏好摘要，逐段重写 / 缩短 / 重配，确认后才继续下一步。

打开页面

C5成片与导出

导出前逐项核对产物版本，过期则阻断并提供一键更新；修复后切换为 MP4 / 剪映草稿双出口。

打开页面

C6任务中心

进行中 / 等待确认 / 失败 / 已完成 / 排队五种状态，状态直接来自管线事实。失败任务只重跑受影响的那一步。

打开页面

C7动作卡与影响预览

模型只出动作建议，用户看到 diff、受影响步骤与耗时后才应用。展示建议 → 已执行 → 可撤回的完整生命周期。

打开页面

C8失败与修复

说清失败原因、已尝试什么、上游哪些产物仍有效，给出三种修法及各自代价，而不是只放一个“重试”。

打开页面
关于风格：页面只复用现有令牌（--bg-* / --accent / --glass-* / --shadow-*），没有引入新的品牌色或字体体系； 步骤名称、配方命名与提示文案都围绕现有产品语境展开。原型仅用于评审交互与信息层级，不包含真实数据。
