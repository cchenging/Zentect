**一句话**：左栏只改参数，右栏只出产物，大屏预览常驻右栏、随时可切回。

```
┌ ed-top：Z / 项目名 / 已保存 / 导出 / 通知 / 设置 / 窗控 ─────────────┐
├ 左栏 35% ────────────┬ 右栏 65% ────────────────────────────────────┤

│ 当前步骤标题+状态    │ ┌ 主视区（按 chips 切换）──────────────────┐              │

└──────────────────────┴────────────────────────────────────────────┘
```

|---|---|---|
| 1 素材助理 | OP/ED 裁剪、抽帧密度、ASR 模型/语言/专名热词、BGM | 关键帧（点帧→预览定位） |
